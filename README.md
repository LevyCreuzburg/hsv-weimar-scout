# Handball Scout

Browser-App zur Live-Erfassung von Handball-Spielaktionen.

## Lokal starten

`index.html` im Browser öffnen. Es ist kein Server und keine Installation nötig.

## Über einen Link öffnen

Den gesamten Ordner auf einen statischen Webhost laden, zum Beispiel GitHub Pages, Netlify oder Vercel. Danach kann jede Person den erzeugten Link auf Handy, Tablet oder PC öffnen.

## Daten

Der aktuelle Spielstand wird automatisch im Browser gespeichert. Über **Export** kann er als JSON-Datei gesichert und auf einem anderen Gerät über **Import** wieder geladen werden.
